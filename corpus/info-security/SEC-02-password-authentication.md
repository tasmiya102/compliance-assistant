# Password & Authentication Policy

Document ID: SEC-02

Category: Information Security

Effective Date: January 1, 2026



## Section 1: Purpose

1.1 This policy defines minimum standards for passwords and authentication

used to access Solara Technologies Inc. systems.



## Section 2: Password Requirements

2.1 Passwords must be a minimum of 14 characters and include a mix of

uppercase, lowercase, numbers, and symbols.



2.2 Passwords must not be reused across the last 10 passwords used for the

same account.



## Section 3: Multi-Factor Authentication

3.1 Multi-factor authentication (MFA) is required for all access to

systems containing Confidential or Restricted data (per PRIV-02).



3.2 MFA is required for all remote access to company systems, per the

Remote Work & Device Security Policy (SEC-04).



## Section 4: Account Lockout

4.1 Accounts are automatically locked after 5 consecutive failed login

attempts and require IT verification to unlock.



## Section 5: Shared Accounts

5.1 Shared or generic login accounts are prohibited except where approved

in writing by the Security team for specific system requirements.
