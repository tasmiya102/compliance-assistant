# Software & System Patching Policy

Document ID: SEC-07

Category: Information Security

Effective Date: January 1, 2026



## Section 1: Purpose

1.1 This policy establishes timelines for applying security patches to

Solara Technologies Inc. systems and software.



## Section 2: Patch Timelines

2.1 Critical security patches must be applied within 72 hours of release.



2.2 High severity patches must be applied within 7 days of release.



2.3 Medium and Low severity patches must be applied within 30 days of

release as part of routine maintenance cycles.



## Section 3: Testing

3.1 Patches for production systems must be tested in a staging environment

before deployment, except where a Critical patch requires emergency

deployment.



## Section 4: Unsupported Software

4.1 Software that no longer receives security patches from its vendor must

be decommissioned or replaced within 90 days of end-of-support notification.
